# UX Principles Reference

## First-Viewport Principle

The first viewport should establish:
- identity
- value
- relevance
- next action

## Information Hierarchy

Use four levels:

1. Primary message/action
2. Supporting information
3. Proof/reassurance
4. Secondary exploration

## Progressive Disclosure

Show only what is necessary at each stage.

Essential → Useful → Advanced → Optional

## Visual Anchoring

Every section should have a clear visual starting point.

Use headings, imagery, whitespace, numbers, cards and contrast to establish orientation.

## Scanning

Design for scanning:
- short paragraphs
- descriptive headings
- strong visual anchors
- logical grouping
- appropriate whitespace

## CTA Principles

A CTA should answer:
“What happens when I click?”

Good:
- Start free trial
- See how it works
- Build my plan
- Choose a plan

Avoid generic labels when a more concrete label is possible.

## Objection Handling

Common objections:
- price
- fit
- trust
- complexity
- cancellation
- post-purchase process
- guarantee

Resolve objections near the relevant decision point.

## Scroll Structure

A useful pattern:

Hook
↓
Problem
↓
Proof
↓
Solution
↓
Benefits
↓
Differentiation
↓
Trust
↓
Offer
↓
Action

Do not add sections without purpose.

## One-Screen-Ahead Principle

At each stage ask:

“What does the visitor need to know right now to confidently move forward?”

Reveal complexity only when necessary.

## Next Thought Test

For each section define:
- current thought
- desired thought
- next section

## Next Action Test

For each important section define the next logical action.

## Component Purpose

Every component should have a clear:
- purpose
- user question
- desired emotion
- desired action
- visual priority

## Mobile UX

Preserve hierarchy rather than simply shrinking desktop layouts.

## Accessibility

Accessibility is part of UX:
- semantic HTML
- keyboard support
- focus states
- contrast
- readable text
- screen-reader support
- reduced motion
- touch-friendly controls

## Performance

Fast interfaces improve perceived quality.

Prioritize optimized assets, efficient code, minimal unnecessary dependencies and stable layouts.
