# Psychology Reference

This document explains the psychological concepts used by the skill.

## Cognitive Fluency

People generally process familiar, clear and well-structured information more easily.

Design implications:
- clear language
- predictable layouts
- consistent components
- readable typography
- obvious interactions
- logical grouping

## Hick's Law

More choices can increase decision complexity.

Design implications:
- reduce unnecessary choices
- group options
- use sensible defaults
- make recommendations clear
- preserve meaningful user control

## Choice Architecture

The interface influences how users evaluate available options.

Use it to make common and appropriate choices easier to understand.

Never hide important alternatives.

## Social Proof

People use evidence from other people to reduce uncertainty.

Useful forms:
- genuine reviews
- genuine testimonials
- real customer counts
- verified results
- relevant customer logos
- credible authority

Never fabricate social proof.

## Loss Aversion

People can be motivated by avoiding a genuine negative outcome.

Use factual consequences to explain value. Never manufacture fear.

## Scarcity

Scarcity can increase perceived value when it is real.

Use only genuine:
- inventory limits
- deadlines
- capacity limits
- promotions

Never use fake countdowns or fake stock levels.

## Commitment and Consistency

Breaking a complex action into meaningful steps can reduce perceived effort.

Example:

Explore → Choose → Preview → Personalize → Complete

Every step must remain transparent.

## Goal Gradient

Visible progress can increase motivation to complete a task.

Useful patterns:
- progress indicators
- completion percentages
- milestones
- checklists

## Zeigarnik Effect

Incomplete tasks can remain mentally salient.

Use completion indicators to help users finish useful tasks. Never deliberately create confusion to pressure completion.

## Anchoring

People often evaluate options relative to contextual reference points.

Use legitimate comparison and pricing context. Never invent inflated anchors.

## Default Effect

Defaults influence decisions.

Use defaults that are genuinely useful and easy to change.

Never preselect unwanted purchases, subscriptions or privacy-invasive choices.

## Reciprocity

Providing genuine value before requesting commitment can improve trust.

Examples:
- useful calculators
- previews
- demos
- guides
- samples

The value must be real.

## Emotional Progression

A strong experience often moves users through:

Confusion → Recognition → Curiosity → Desire → Trust → Confidence → Action

The exact sequence depends on the product.
