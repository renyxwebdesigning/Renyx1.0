# UX Audit Checklist

Use this checklist after implementation.

## 1. First 5 Seconds

[ ] Is the purpose immediately clear?
[ ] Is the target audience apparent?
[ ] Is the main benefit obvious?
[ ] Is the next action obvious?

## 2. Hero

[ ] Clear eyebrow/context?
[ ] Specific headline?
[ ] Strong value proposition?
[ ] One clear primary CTA?
[ ] Appropriate reassurance or proof?

## 3. Information Hierarchy

[ ] Is there one dominant message?
[ ] Are secondary elements subordinate?
[ ] Can the page be scanned quickly?
[ ] Are sections visually distinct?
[ ] Is unnecessary content removed?

## 4. Visitor Journey

[ ] Attention established?
[ ] Relevance established?
[ ] Problem understood?
[ ] Solution understood?
[ ] Desire created?
[ ] Trust established?
[ ] Objections addressed?
[ ] Action made obvious?

## 5. Psychology

[ ] Cognitive load minimized?
[ ] Choices simplified?
[ ] Defaults useful?
[ ] Progress visible where needed?
[ ] Social proof genuine?
[ ] Scarcity genuine?
[ ] No manufactured fear?
[ ] No dark patterns?

## 6. CTA

[ ] Does the CTA explain the outcome?
[ ] Is the primary CTA visually dominant?
[ ] Does it appear at decision points?
[ ] Is the next step predictable?

## 7. Trust

[ ] Real proof?
[ ] Claims substantiated?
[ ] Pricing transparent?
[ ] Cancellation transparent?
[ ] Important risks explained?

## 8. Forms

[ ] Only necessary fields?
[ ] Clear labels?
[ ] Inline validation?
[ ] Useful error messages?
[ ] Input preserved after errors?
[ ] Required fields obvious?

## 9. Mobile

[ ] Hierarchy preserved?
[ ] CTA accessible?
[ ] Text readable?
[ ] Tap targets large enough?
[ ] No unnecessary horizontal scrolling?
[ ] No excessive dead space?

## 10. Accessibility

[ ] Semantic HTML?
[ ] Keyboard navigation?
[ ] Visible focus states?
[ ] Sufficient contrast?
[ ] Meaningful alt text?
[ ] Screen-reader-friendly?
[ ] Reduced-motion support?

## 11. Performance

[ ] Images optimized?
[ ] Fonts efficient?
[ ] Unnecessary JavaScript removed?
[ ] Layout shift minimized?
[ ] Initial rendering fast?

## 12. Final Scoring

Score each from 1–10:

Clarity: __/10
Value proposition: __/10
Visual hierarchy: __/10
Cognitive fluency: __/10
Trust: __/10
Social proof: __/10
Navigation: __/10
CTA clarity: __/10
Friction: __/10
Mobile UX: __/10
Accessibility: __/10
Performance: __/10
Emotional progression: __/10
Overall conversion UX: __/10

## Interpretation

8–10 = strong
7 = acceptable but investigate
5–6 = improvement required
1–4 = major problem

Any category below 7 should be investigated.
Any category below 5 should normally be fixed before completion.
