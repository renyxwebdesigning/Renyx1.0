## Purpose

This skill helps Claude Code design websites that guide visitors naturally from:

**Attention → Understanding → Relevance → Desire → Trust → Action**

It focuses on:
- UX psychology
- behavioral design
- conversion UX
- cognitive fluency
- visual hierarchy
- information architecture
- choice architecture
- social proof
- CTA design
- objection handling
- emotional progression
- mobile UX
- accessibility
- performance
- ethical persuasion

## Recommended workflow

Claude should:

1. Inspect the existing project.
2. Understand the visitor and business goal.
3. Map the visitor journey.
4. Define the information architecture.
5. Create or validate the wireframe.
6. Define the visual hierarchy.
7. Implement the interface.
8. Test the experience.
9. Run the UX audit.
10. Iterate.

## Ethical philosophy

The skill is designed for persuasion without deception.

Never fabricate proof or create fake urgency, fake scarcity, hidden costs, confusing cancellation flows, manipulative defaults or other dark patterns.
