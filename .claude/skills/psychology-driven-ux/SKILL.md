# Psychology-Driven UX

## Mission

Build websites that do more than look good. Design the experience so visitors naturally understand where they are, what is offered, why it matters, why they should trust it, what to do next, and what happens after they act.

Use psychology to improve clarity, motivation, confidence and decision-making. Never use deception or dark patterns.

## Core Journey

ATTENTION → ORIENTATION → RELEVANCE → CURIOSITY → DESIRE → TRUST → LOW FRICTION → ACTION → CONFIRMATION

Every major section must have a clear purpose in this journey.

## Before Coding

Never immediately start coding. First inspect the project structure, framework, routes, components, styling, assets, typography, existing UX and responsive behavior.

Then define:
- target audience
- visitor intent
- business objective
- desired conversion
- visitor problem
- desired outcome
- objections
- trust barriers

## First 5 Seconds

The visitor should quickly understand:
- What is this?
- Who is it for?
- What benefit does it provide?
- What should I do?

Typical hero:
EYEBROW → HEADLINE → VALUE PROPOSITION → PRIMARY CTA → TRUST / REASSURANCE

Prefer specific outcomes over vague marketing language.

## UX Principles

Apply cognitive fluency, progressive disclosure, choice architecture, Hick's Law, scanning behavior, visual anchoring, trust architecture, social proof, ethical loss aversion, real scarcity, commitment and consistency, goal gradients, clear CTAs, objection handling and emotional progression.

See:
- `references/psychology.md`
- `references/ux-principles.md`

## Design Rules

Create strong visual hierarchy. Use typography, size, whitespace, contrast, position, grouping, imagery and motion intentionally.

Do not make every element visually loud.

Use one primary action and, where useful, one secondary action.

Reveal complexity gradually.

Design for scanning rather than assuming visitors read every word.

## Trust

Distribute genuine proof throughout the journey. Match proof to the objection it resolves.

Never fabricate testimonials, reviews, statistics, customers, certifications or results.

## Ethical Persuasion

Persuasion should improve understanding and confidence, not remove informed choice.

Never use fake scarcity, fake countdowns, fake urgency, fabricated proof, deceptive pricing, hidden cancellation, forced subscriptions, manipulative defaults or intentionally difficult refusal.

## CTA

CTA labels should communicate the result of clicking.

Prefer:
- Start free trial
- See how it works
- Build my plan
- Choose a plan

Place CTAs at meaningful decision points. Do not spam them.

## Emotional Journey

Design:
CONFUSION → RECOGNITION → CURIOSITY → DESIRE → TRUST → CONFIDENCE → ACTION

Every section should create a logical next thought and next action.

## Implementation Workflow

1. Inspect
2. Understand
3. Model visitor
4. Define journey
5. Structure information
6. Wireframe
7. Design
8. Implement
9. Test
10. Audit
11. Iterate

Do not begin with decorative styling.

## Component Psychology

For important components define:
- Component
- Purpose
- User question
- Psychological principle
- Desired emotion
- Desired action
- Visual priority

## Mobile, Accessibility and Performance

Do not simply shrink desktop designs.

Preserve hierarchy on mobile. Use readable typography, thumb-friendly controls and clear CTAs.

Always use semantic HTML, keyboard navigation, focus states, accessible contrast, screen-reader compatibility, reduced-motion support, meaningful alt text, sufficient tap targets and clear form errors.

Prioritize optimized images, efficient fonts, minimal unnecessary JavaScript, appropriate lazy loading, reduced layout shift and fast initial rendering.

## Premium and Modern Design

Premium does not mean adding gradients, shadows, glassmorphism, huge radii or excessive animation.

Instead improve typography, spacing, composition, imagery, hierarchy, consistency, interaction quality and copy precision.

Modern design should generally have strong typography, clear hierarchy, intentional whitespace, restrained visual language, subtle motion, responsive design and clear interactions.

## Mandatory Audit

Score 1–10:
- Clarity
- Value proposition
- Visual hierarchy
- Cognitive fluency
- Trust
- Social proof
- Navigation
- CTA clarity
- Friction
- Mobile UX
- Accessibility
- Performance
- Emotional progression
- Overall conversion UX

Anything below 7 requires investigation. Anything below 5 should normally be fixed.

## Final Standard

The website should feel:
OBVIOUS → INTERESTING → RELEVANT → TRUSTWORTHY → DESIRABLE → EASY → ACTIONABLE

The visitor should think:
“This makes sense.”
“This is relevant to me.”
“I trust this.”
“I know what to do next.”

Never optimize only for aesthetics. Build a natural, obvious, trustworthy and frictionless user journey.
